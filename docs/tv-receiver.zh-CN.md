# MoonCast TV 接收端（预览版）

这是独立的 Android TV 应用（包名 `com.mooncast.tv`），与仓库内原有手机发送端并存。请下载 GitHub Release 的 **TV APK**，不要当成手机发送端更新。

- 实现真实 UxPlay AirPlay 镜像 / 音频接收、PIN 配对与原生硬件解码；不是只注册一个设备名称。
- 实现 DLNA 设备发现、媒体地址播放、暂停、定位、音量 / 静音及状态事件。DLNA 不等于手机屏幕镜像。
- 支持保留比例、铺满、手动对称裁剪、稳定黑边锁定，以及自适应视频清晰度上限。
- 不支持或冒充 Google Cast、Miracast、AirPlay 2 多房间，也不绕过 DRM 或应用限制。
- 此 TV 应用不实现 Moonlight / GameStream 客户端；原 MoonCast 手机发送端仍需官方 Moonlight 接收。
- 所有真实 iPhone / Android TV 互通与画音性能仍需验收；构建成功不等于全部设备已兼容。

## 使用

1. 在 Android 8.0+ 电视安装 TV APK（ARM64 / ARMv7，另含 x86_64 测试架构）。预览版使用调试签名；不同 CI 发布可能使用不同密钥，升级可能要卸载旧版，清除偏好与配对记录。尚未配置稳定正式签名升级。
2. 手机与电视接入同一可信局域网，打开应用并点“启动接收”。
3. iPhone 从“屏幕镜像”选择电视显示的名称，按提示输入电视上的 PIN。DLNA 应用则选择该渲染器播放未加密的媒体。
4. 遥控器确认 / 菜单显示控制，返回可停止并退出。离开应用会停止所有接收，不会在后台继续监听。

同一时间只播放一个来源。DLNA 接管时会暂停 AirPlay 接收以避免声音重叠；停止媒体后恢复 AirPlay 发现。网络变化会停止旧播放并在新局域网重新发现。

智能影院需连续稳定黑边后锁定，遇到内容变化请重新检测，暗场或特殊字幕可能误判。手动模式左右、上下各最多裁剪 25%，保持比例；不会把画面拉伸变形。画质上限只选择发送源现有轨道，不会“无损补画质”。

请勿把端口映射到互联网。DLNA 同网设备可以请求播放；AirPlay 原生监听所有可用接口。完整协议限制、构建步骤、许可来源、实机验收清单见 [英文详细文档](tv-receiver.md)。发布附件包括 APK、对应源码包与 SHA256SUMS。
